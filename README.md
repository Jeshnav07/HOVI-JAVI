# HOVI-JAVI

HOVI & JAVI is a responsive and user-friendly travel guide website designed to help users explore the most popular and culturally rich destinations across India. This platform enables travelers to discover new places, read travel blogs, post reviews, and plan their trips with ease.

🔧 Technologies Used
Frontend: HTML, CSS, JavaScript, Bootstrap

Backend: PHP

Database: MySQL (managed via PHPMyAdmin)

✨ Key Features
Destination listings with images and descriptions

Travel blogs and user reviews

User registration and login system

Admin panel for managing destinations, blogs, and feedback

Mobile-friendly responsive design

📌 Project Goals
The goal of this project is to offer an informative and interactive travel planning experience, with dedicated sections for both users and admins. It emphasizes clean UI/UX, functionality, and easy content management.

🚀 Getting Started
To run this project locally:

Clone this repository. 

Import the SQL database into PHPMyAdmin.

Configure database credentials in the PHP files.

Launch it on a local server (e.g., XAMPP or WAMP).
